Everything lives in the open on GitHub. You propose changes by pull request, and we talk them through on Discord. For the full mechanics — branching, sign-off, and the licensing model — see the [contribution guide](/contributing).

## Research

The research area is our epistemic chain: **observations** we record, **insights** we draw from them, **hypotheses** we test, and the **reports** that compile findings. You can add a source, sharpen an argument, flag a weak link in the chain, or propose a study.

Browse what's there at [Research](/research), then open a pull request or raise it on Discord first if you'd like to talk it through.

## Resources

Resources are the practical layer — the **wiki** (encyclopedic reference), the **glossary** (shared definitions), and the **library** (recommended reading). Define a term, add a library entry, improve an explanation, or fix a broken link.

Start from [Resources](/resources). Glossary and wiki entries are short and a great first contribution.

## Thinking

Thinking is our point of view — **essays** and the **manifesto**. Argue a position, respond to an existing piece, or draft something new. This is the most editorial area, so substantial pieces go through review on the way in.

See [Thinking](/thinking) for the current writing.

## Website &amp; tech

The site and the tooling behind it are open too. Fix a bug, refine a component, improve accessibility, or help with the build and content pipeline. If you write code, this is your way in.

The code lives in the [GitHub organization](https://github.com/co-goods) — open an issue or a pull request.
