## Where we collaborate

We work in two places, both public. **Discord** is where the conversation happens — questions, ideas, our calls, and what we need help with. **GitHub** is where the work lives — every change goes through a pull request. Join one or both.

```prose
id: discord
```
### Discord

The easiest way in. You don't have to contribute code or content to belong — come and talk, ask a question, or jump into a working session.

```cta
variant: primary
```

### GitHub

Everything that becomes the site — research, writing, and the code — lives in public repositories. Read it, fork it, watch the work, or open an issue or pull request.

## Help wanted

The fastest way to find something concrete to do. We post specific asks — each one a post you can pick up — in the **help-wanted** forum on Discord. It's the go-to place to see what's needed right now.

## Research

The research area is our epistemic chain: **observations** we record, **insights** we draw from them, **hypotheses** we test, and the **reports** that compile findings. You can add a source, sharpen an argument, flag a weak link in the chain, or propose a study.

Browse what's there at [Research](/research), then open a pull request — or talk it through in the channel first.

```cta
label: Join the conversation
href: discord:research
variant: secondary
```

```prose
id: resources
```
## Resources

Resources are the practical layer — the **wiki** (encyclopedic reference), the **glossary** (shared definitions), and the **library** (recommended reading). Define a term, add a library entry, improve an explanation, or fix a broken link.

Start from [Resources](/resources). Glossary and wiki entries are short and a great first contribution.

```cta
label: Join the conversation
href: discord:resources
variant: secondary
```

## Thinking

Thinking is our point of view — **essays** and the **manifesto**. Argue a position, respond to an existing piece, or draft something new. This is the most editorial area, so substantial pieces go through review on the way in.

See [Thinking](/thinking) for the current writing.

```cta
label: Join the conversation
href: discord:thinking
variant: secondary
```

```prose
id: tech
```

## Tech

Tech in general — the website, apps, tools, and the tooling behind it all. Fix a bug, refine a component, improve accessibility, or help with the build and content pipeline. If you build things, this is your way in.

The code lives in the [GitHub organization](/community/github) — open an issue or a pull request.

```cta
label: Join the conversation
href: discord:tech
variant: secondary
```
