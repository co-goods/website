## What's on our GitHub

Co-Goods is developed in the open. Everything that becomes the website lives in two public repositories:

- **content** — the research, writing, wiki, glossary, and library. Plain markdown, edited by pull request.
- **website** — the Next.js app that renders it all.

You can read everything, fork it, or propose a change. Spot a typo, a broken link, a weak argument, or a bug? Open an issue or a pull request. If you're not sure where to start, see [how to contribute](/community/contributing).
